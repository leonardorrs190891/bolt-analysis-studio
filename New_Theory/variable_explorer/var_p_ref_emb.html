FísicaPhysics

É a pressão de referência da conformação de embedding: a pressão de aperto na qual o fator S_conf vale 1. Abaixo dela a junta ainda tem assentamento residual pleno; acima, o assentamento vai sendo progressivamente pré-consumido no torque. Fixa onde fica o joelho de pressão.

S_conf depende da RAZÃO p_ref_emb/p_init, então subir p_ref_emb empurra o fator na direção de 1 (mais embedding residual, queda inicial mais funda) e baixa-lo encolhe o embedding. Nesta página o companheiro emb_conform_exp=2 está ligado para o fator agir; o slider desloca a pressão em que o reservatório se enche. Um detalhe: esta mesma âncora é reusada pelo canal lento (creep_conform_exp).

Só é LIDA se algum expoente de conformação for > 0 (senão inerte). É uma âncora per-rig, como emb_depth; o default de 1.5e8 Pa (~150 MPa) vale para o rig UFU.

This is the reference pressure of the embedding conformance: the clamp pressure at which the factor S_conf equals 1. Below it the joint still has full residual settling; above it, settling is progressively pre-consumed at torque. It sets where the pressure knee sits.

S_conf depends on the RATIO p_ref_emb/p_init, so raising p_ref_emb pushes the factor toward 1 (more residual embedding, deeper initial drop) and lowering it shrinks embedding. On this page the companion emb_conform_exp=2 is enabled so the factor is active; the slider shifts the pressure at which the reservoir fills. One subtlety: this same anchor is reused by the slow channel (creep_conform_exp).

It is only READ if some conformance exponent is > 0 (inert otherwise). It is a per-rig anchor, like emb_depth; the default of 1.5e8 Pa (~150 MPa) fits the UFU rig.

EquaçãoEquation

S_conf = min(1, (p_ref_emb / p_init)^n_conf), p_init = F0_init / A_contact
