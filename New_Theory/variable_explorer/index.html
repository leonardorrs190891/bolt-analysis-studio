Documentação interativa das variáveis do modelo V2 (DynamicStiffnessAnalyzer) Interactive documentation of the V2 model variables (DynamicStiffnessAnalyzer)

Uma página por campo de JointMaterial (129 no total: 11 constante física, 97 forma opt-in, 16 modo (discreto), 5 numérico). Escolha uma variável no sumário à esquerda. Cada página mostra a curva-padrão de afrouxamento (F/F0 vs ciclo) e um controle que muda a variável e reforma a curva ao vivo, mais a física, a equação e as referências de literatura. One page per JointMaterial field (129 total: 11 physical constant, 97 opt-in form, 16 mode (discrete), 5 numerical). Pick a variable in the sidebar on the left. Each page shows the standard loosening curve (F/F0 vs cycle) and a control that changes the variable and reshapes the curve live, plus the physics, the equation and the literature references.

Por padrão o sumário mostra só as constantes físicas (as ~10 do fit canônico). Use as caixas no topo do sumário para revelar também as formas/modos opt-in e as variáveis numéricas/raras (de efeito negligível na curva). A busca por texto encontra qualquer variável, independente dessas caixas. By default the sidebar shows only the physical constants (the ~10 in the canonical fit). Use the checkboxes at the top of the sidebar to also reveal the opt-in forms/modes and the numerical/rare variables (negligible effect on the curve). The text search finds any variable regardless of those checkboxes.

A curva-padrãoThe standard curve

Salvo indicação, todas as curvas partem do mesmo ensaio de referência (rig UFU): parafuso M16 em cisalhamento (Junker), arruela nova, pré-carga F0 = 50 kN, amplitude imposta δ = 0.5 mm a 0.5 Hz, carga transversal (θ = 90°), 2500 ciclos, modo de deslocamento. As curvas são pré-computadas pelo engine real (handle_simulate) — não há física reimplementada em JavaScript. Alguns campos (fretting axial, fadiga, creep) usam um baseline axial ou de creep, indicado na própria página. Unless noted, every curve starts from the same reference test (UFU rig): M16 bolt in shear (Junker), new washer, preload F0 = 50 kN, imposed amplitude δ = 0.5 mm at 0.5 Hz, transverse load (θ = 90°), 2500 cycles, displacement mode. Curves are pre-computed by the real engine (handle_simulate) — no physics is reimplemented in JavaScript. A few fields (axial fretting, fatigue, creep) use an axial or creep baseline, noted on the page itself.
