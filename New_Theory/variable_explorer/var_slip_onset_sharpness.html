FísicaPhysics

Nitidez do gate de incubação do estágio 1. É o expoente k na sigmoide de Hill g = x^k/(x^k+1), com x = W_slip_acc/slip_onset_W, que controla quão ABRUPTA é a passagem do platô (estágio 1) para o colapso (estágio 2). Só é lido se slip_onset_W > 0.

Mover o slider (1…8) muda a forma do joelho: k grande = platô mais chato e queda súbita; k pequeno = transição gradual. Default 4; companheiro slip_onset_W, que fixa QUANDO (em dose de slip acumulada) a incubação termina.

Sharpness of the stage-1 incubation gate. It is the exponent k in the Hill sigmoid g = x^k/(x^k+1), with x = W_slip_acc/slip_onset_W, which controls how ABRUPT the passage from plateau (stage 1) to collapse (stage 2) is. It is only read if slip_onset_W > 0.

Moving the slider (1…8) changes the knee shape: large k = a flatter plateau and a sudden drop; small k = a gradual transition. Default 4; companion slip_onset_W, which sets WHEN (in accumulated slip dose) the incubation ends.

EquaçãoEquation

g = x^k / (x^k + 1), x = W_slip_acc / slip_onset_W, k = slip_onset_sharpness
