FísicaPhysics

É a amplitude relativa de referência da unificação ρ: o valor de ρ = F_ax_amp/F0 no qual o fator de assentamento por amplitude satura em 1. Define a escala de amplitude sobre a qual o assentamento extra se acumula.

S_ρ depende de ρ/rho_ref_emb, então um rho_ref_emb maior empurra o fator para baixo (menos assentamento dirigido por amplitude para a mesma amplitude) e um menor o aumenta. Nesta página o companheiro emb_amp_exp=3 está ligado; o slider desloca a amplitude em que o reservatório se enche − quando rho_ref se iguala ao ρ do ensaio, S=1 e a queda inicial é máxima.

Só é LIDA se emb_amp_exp > 0 (senão inerte). É uma âncora per-rig; o default é 0.667.

This is the reference relative amplitude of the ρ-unification: the value of ρ = F_ax_amp/F0 at which the amplitude settling factor saturates to 1. It sets the amplitude scale over which the extra settling accumulates.

S_ρ depends on ρ/rho_ref_emb, so a larger rho_ref_emb pushes the factor down (less amplitude-driven settling for the same amplitude) and a smaller one raises it. On this page the companion emb_amp_exp=3 is enabled; the slider shifts the amplitude at which the reservoir fills − when rho_ref matches the test ρ, S=1 and the initial drop is maximal.

It is only READ if emb_amp_exp > 0 (inert otherwise). It is a per-rig anchor; the default is 0.667.

EquaçãoEquation

S_rho = min(1, (rho / rho_ref_emb)^q_amp), rho = F_ax_amp / F0_init
