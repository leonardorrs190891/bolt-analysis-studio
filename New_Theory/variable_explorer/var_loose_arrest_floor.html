FísicaPhysics

Quando o afrouxamento é do tipo runaway (o torque resistivo T_resist cai proporcionalmente a F_0, então quanto mais afrouxa mais fácil afrouxar), a curva desabaria até zero. Fisicamente isso não acontece: a zona de stick central do contato (Cattaneo-Mindlin) restaura o atrito estático da rosca e trava um clamp residual contra o off-torque da hélice. loose_arrest_floor é esse piso, como fração da pré-carga inicial: F_min = loose_arrest_floor·F_0_init.

Na equação o gate g = max(0, 1 − F_min/F_0) multiplica d_theta: o ratcheting só drena o EXCESSO acima de F_min, então quando F_0 → F_min a rotação para. O runaway vira uma S-curve com ponto fixo ESTÁVEL em F_min. Subir o slider levanta o platô final da curva. O contexto liga o runaway (bolt_torsion + gross_fraction + bending) para o arresto ser visível.

Lido do fim do dado (o platô residual), O(0.05–0.10) por par. É o que torna o modo bolt_torsion ADOTÁVEL − remove o over-collapse do #10 (§4.10). Opt-in, default 0 = OFF (sem arresto, runaway).

When loosening is of the runaway type (the resisting torque T_resist falls proportionally to F_0, so the more it loosens the easier it loosens), the curve would collapse to zero. Physically it does not: the central stick zone of the contact (Cattaneo-Mindlin) restores static thread friction and locks a residual clamp against the helix off-torque. loose_arrest_floor is that floor, as a fraction of the initial preload: F_min = loose_arrest_floor·F_0_init.

In the equation the gate g = max(0, 1 − F_min/F_0) multiplies d_theta: ratcheting only drains the EXCESS above F_min, so when F_0 → F_min the rotation stops. The runaway becomes an S-curve with a STABLE fixed point at F_min. Raising the slider lifts the curve's final plateau. The context turns the runaway on (bolt_torsion + gross_fraction + bending) so the arrest is visible.

Read from the tail of the data (the residual plateau), O(0.05–0.10) per pair. It is what makes the bolt_torsion mode ADOPTABLE − it removes the over-collapse of #10 (§4.10). Opt-in, default 0 = OFF (no arrest, runaway).

EquaçãoEquation

F_min = loose_arrest_floor*F_0_init; g_arrest = max(0, 1 - F_min/F_0); d_theta *= g_arrest (stable fixed point at F_min)
