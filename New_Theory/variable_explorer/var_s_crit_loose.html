FísicaPhysics

s_crit_loose é a amplitude crítica de slip que precisa ser excedida para o afrouxamento graduado começar. Abaixo de s_crit a interface micro-escorrega mas não gira a porca (platô / não-inicia); acima dele, só o excesso slip − s_crit dirige a rotação.

Ele entra no kernel graduado, Δθ = gates × k_loose_graded × max(0, slip − s_crit_loose)/(d_2/2). Como o slip corrente modula a taxa a cada ciclo, um espectro de amplitudes morde de forma diferente; como s_crit é FIXO (não ~F_0), não há runaway. Mover o slider (log) alonga o platô e pode suprimir o colapso por completo (todos os ciclos sub-críticos) ao subir, ou deixar até curso pequeno afrouxar ao descer.

Só age quando loose_rate_mode=graded_scrit (o contexto liga o modo e fixa k_loose_graded=1.0). PER-RIG com proveniência: lido da curva amplitude-vs-vida (Bauer 76-108 µm, s_crit ~99 µm). Em 0 volta ao kernel de torque.

s_crit_loose is the critical slip amplitude that must be exceeded for graded loosening to start. Below s_crit the interface micro-slips but does not turn the nut (plateau / non-start); above it, only the excess slip − s_crit drives rotation.

It enters the graded kernel, Δθ = gates × k_loose_graded × max(0, slip − s_crit_loose)/(d_2/2). Because the current slip modulates the rate each cycle, a spectrum of amplitudes bites differently; because s_crit is FIXED (not ~F_0), there is no runaway. Moving the slider (log) lengthens the plateau and can suppress the collapse entirely (all cycles sub-critical) when raised, or let even a small stroke loosen when lowered.

It acts only when loose_rate_mode=graded_scrit (the context enables the mode and sets k_loose_graded=1.0). PER-RIG with provenance: read from the amplitude-vs-life curve (Bauer 76-108 µm, s_crit ~99 µm). At 0 it falls back to the torque kernel.

EquaçãoEquation

Delta_theta = gates * k_loose_graded * max(0, slip - s_crit_loose)/(d_2/2) (slip <= s_crit_loose => 0)
