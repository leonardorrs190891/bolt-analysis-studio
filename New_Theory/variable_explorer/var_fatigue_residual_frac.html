FísicaPhysics

Depois que o cliff dispara, sobra algum aperto? fatigue_residual_frac (f_res) é a fração da pré-carga ORIGINAL (F_0_init) que sobrevive a fratura. f_res = 0 é fratura total (o parafuso solta, F_0 → 0); f_res > 0 modela uma fratura parcial ou um caminho de carga residual (engajamento de rosca remanescente, um segundo parafuso, um batente) que ainda segura parte da força.

No ciclo de fratura o modelo aplica ΔF_0 = −(F_0 − f_res·F_0_init), ou seja F_0 salta direto para f_res·F_0_init. Mover o slider levanta o piso em que o cliff aterrissa − quanto mais fundo cai a curva. Ele NÃO muda onde o cliff acontece (isso é governado pelos parâmetros da S-N e pela tensão); só muda a profundidade da queda.

Proveniência: é um clamp fenomenológico do evento estrutural (a energética do cliff é a energia elástica liberada, roteada para W_diss_fracture). Default 0 = fratura total, o caso conservador.

After the cliff fires, does any clamp survive? fatigue_residual_frac (f_res) is the fraction of the ORIGINAL preload (F_0_init) that outlives fracture. f_res = 0 is total fracture (the bolt lets go, F_0 → 0); f_res > 0 models a partial fracture or a residual load path (remaining thread engagement, a second bolt, a stop) that still carries some force.

On the fracture cycle the model applies ΔF_0 = −(F_0 − f_res·F_0_init), so F_0 jumps straight to f_res·F_0_init. Moving the slider raises the floor the cliff lands on − how deep the curve drops. It does NOT move where the cliff happens (that is set by the S-N parameters and the stress); it only sets the depth of the fall.

Provenance: a phenomenological clamp on the structural event (the cliff energetics are the released elastic energy, routed to W_diss_fracture). Default 0 = total fracture, the conservative case.

EquaçãoEquation

at fracture (D_fat >= 1): dF_0 = -(F_0 - f_res*F_0_init) => F_0 -> f_res*F_0_init
