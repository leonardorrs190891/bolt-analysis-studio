FísicaPhysics

fat_sigma_knee (σ_knee) é o joelho da curva S-N (Wohler) bilinear: a tensão em que a inclinação muda de m_1 (ramo de alta tensão / baixo ciclo) para m_2 (ramo pós-joelho / alto ciclo). É a fronteira entre os dois regimes de fadiga. Default 50 MPa (parametrização Yang).

Na equação, o joelho escolhe QUAL ramo de sun_life vale: σ_ar ≥ σ_knee usa C_1/m_1; abaixo usa C_2/m_2. Mover o joelho muda em que regime a tensão equivalente de operação cai, alterando N_f e, com isso, a posição do cliff. Ressalva desta curva: no baseline axial de amplitude alta σ_ar fica bem ACIMA de qualquer valor da faixa (30–80 MPa), então o ponto de operação permanece no ramo C_1/m_1 e mover o joelho quase não reforma ESTA curva − ele decide o regime só em carregamento de baixa amplitude / vida muito longa.

Proveniência: joelho da bilinear de Yang; é por material.

fat_sigma_knee (σ_knee) is the knee of the bilinear S-N (Wohler) curve: the stress where the slope switches from m_1 (high-stress / low-cycle branch) to m_2 (post-knee / high-cycle branch). It is the boundary between the two fatigue regimes. Default 50 MPa (Yang parametrization).

In the equation the knee chooses WHICH branch of sun_life applies: σ_ar ≥ σ_knee uses C_1/m_1; below it uses C_2/m_2. Moving the knee changes which regime the operating equivalent stress sits in, altering N_f and thereby cliff position. Caveat for this curve: in the high-amplitude axial baseline σ_ar sits well ABOVE the whole range (30–80 MPa), so the operating point stays on the C_1/m_1 branch and moving the knee barely reshapes THIS curve − it only picks the regime under low-amplitude / very-long-life loading.

Provenance: the knee of Yang's bilinear curve; it is per-material.

EquaçãoEquation

N_f = C1*sigma_ar^(-m1) if sigma_ar >= sigma_knee; C2*sigma_ar^(-m2) otherwise
