FísicaPhysics

É o ramo oposto do emb_conform_exp, e as duas coisas acontecem de verdade numa junta. Aquele diz que apertar forte já gastou aspereza − sobra menos para o ciclo consumir. Este diz que o achatamento plástico precisa de pressão para acontecer: numa junta pouco apertada o escoamento das asperezas é pequeno, então o reservatório de assentamento é mais raso. Um faz a assíntota encolher quando a pressão SOBE; o outro, quando ela CAI.

Por que isso importa na prática: sem este fator, a perda de encaixe é uma profundidade quase absoluta, e a mesma profundidade vira uma fração muito maior de uma pré-carga pequena. O resultado é o modelo perder pré-carga demais justamente nos apertos baixos − medido no LU_2024, cuja varredura de torque mostra o excesso de perda no 1º ciclo indo com 1/F0 a r = +0,995.

O min(1, ·) não é enfeite: toda junta com pressão acima da referência fica em S_p = 1 exato, então ligar a lei numa fonte não mexe, nem por arredondamento, nas juntas mais apertadas dela. Capability opt-in, default 0 = OFF (bit-idêntica quando desligada), per-rig.

This is the opposite branch of emb_conform_exp, and both effects are real in a joint. That one says hard tightening already consumed asperities, so less is left for cycling. This one says plastic flattening needs pressure to happen: in a lightly tightened joint asperity yielding is small, so the settling reservoir is shallower. One shrinks the asymptote when pressure RISES; the other, when it FALLS.

Why it matters: without this factor the embedding loss is a nearly absolute depth, and the same depth is a much larger fraction of a small preload − so the model over-loses exactly at low tightening torque. Measured on LU_2024, whose torque sweep shows the excess first-cycle loss scaling as 1/F0 with r = +0.995.

The min(1, ·) is load-bearing: any joint above the reference pressure sits at S_p = 1 exactly, so enabling the law in a source cannot disturb its tighter joints even by rounding. Opt-in capability, default 0 = OFF (bit-identical when off), per-rig.

EquaçãoEquation

delta_target *= S_p; S_p = min(1, (p_init / p_ref_emb)^n_p), p_init = F0_init / A_contact
