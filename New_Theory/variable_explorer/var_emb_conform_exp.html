emb_conform_exp

FísicaPhysics

Apertar a junta com torque alto já achata parte das asperezas antes de qualquer ciclo (a área real de contato cresce ~F0/H). Uma junta muito pré-carregada, então, chega ao ensaio com menos assentamento residual a consumir. Este expoente controla o quão forte a assíntota de embedding encolhe com a pressão de aperto.

Ele multiplica a profundidade-alvo por S_conf = min(1, (p_ref_emb/p_init)^n_conf), com p_init = F0_init/A_contact fixado no INÍCIO do run (nunca o F_0 corrente − sem realimentação, a forma fechada de Norton é preservada). No slider: em 0 o fator vale 1 (inerte, a curva-padrão); ao subir n_conf a queda inicial encolhe, porque a assíntota é escalada para baixo.

Capability opt-in, default 0 = OFF (bit-idêntica quando desligada), per-rig como emb_depth/c_bend. Foi nomeada para inclinar d(final)/dP0 no Liu2017; depois a unificação ρ (emb_amp_exp) mostrou que ela é o caso especial a A_F fixo da mesma física − usa-se UMA das duas por rig (redução de variável).

Tightening the joint at high torque already flattens some asperities before any cycle (the real contact area grows ~F0/H). A heavily preloaded joint therefore arrives at the test with less residual settling left to consume. This exponent controls how strongly the embedding asymptote shrinks with clamp pressure.

It multiplies the target depth by S_conf = min(1, (p_ref_emb/p_init)^n_conf), with p_init = F0_init/A_contact fixed at the START of the run (never the current F_0 − no feedback, so the closed Norton form is preserved). On the slider: at 0 the factor is 1 (inert, the standard curve); raising n_conf shrinks the initial drop, because the asymptote is scaled down.

An opt-in capability, default 0 = OFF (bit-identical when off), per-rig like emb_depth/c_bend. It was named to tilt d(final)/dP0 in Liu2017; the ρ-unification (emb_amp_exp) later showed it is the fixed-A_F special case of the same physics − use ONE of the two per rig (variable reduction).

EquaçãoEquation

delta_target *= S_conf; S_conf = min(1, (p_ref_emb / p_init)^n_conf), p_init = F0_init / A_contact
