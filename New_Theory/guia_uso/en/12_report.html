Report — the document

Bolt Analysis Studio 1.0.0 · Narrated user guide

Listen to the narration · voice: en-US-AndrewNeural

Transcript

The Report module assembles a document from the current analysis. Choose the sections, the format and see the preview. Your joint's report has the same sections as the reports of the paper's cases, because it comes from the same machinery: test conditions, model, curve, decomposition by mechanism and the list of constants. Export as HTML; it opens in the system browser.
