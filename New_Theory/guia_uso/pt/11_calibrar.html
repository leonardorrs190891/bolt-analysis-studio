Calibrar parâmetros (Ctrl+K)

Bolt Analysis Studio 1.0.0 · Guia de uso narrado

Ouça a narração · voz: pt-BR-AntonioNeural

Transcrição

Analisar, Calibrar parâmetros do modelo, ou control K. Primeiro o programa pergunta contra qual curva ajustar: o caso do artigo de onde o modelo veio, ou um CSV seu. Depois abre o diálogo de calibração. À esquerda, a lista de parâmetros, cada um com uma caixa de seleção e dois limites. A regra é simples e é o que faz tudo funcionar: o que você não marca fica exatamente no valor que está no modelo. É assim que se trava o que já foi medido. O que você marca é procurado entre o limite inferior e o superior. Marque poucos por vez. À direita, a prévia mostra a curva experimental, o modelo atual e o ajuste candidato. Aplicar grava o resultado no modelo; Descartar não deixa vestígio. O motor que ajusta é o mesmo que roda a análise: o que fecha aqui se reproduz no Run.

Cada controle desta tela

ControleO que faz
Curva de referência: Caso da validação / Arquivo CSV…A origem da curva experimental. O caso só aparece se o modelo veio de um.
Optimization Agent / Run AgentModo autônomo: detecta o regime, escolhe um prior da literatura e ajusta em duas etapas.
Trim cyclesRecorta a janela de ciclos usada no ajuste: tira uma cauda ruidosa ou um reaperto.
EngineV2 não linear é o recomendado; é o motor do artigo.
Wizard — load literature priors…Carrega limites típicos da literatura para os parâmetros.
Parameter / Lo / HiA caixa trava ou libera; Lo e Hi são os limites da busca.
Live PreviewExperimental, modelo atual e ajuste; MAE e RMSE no topo.
Preview Current / Run Calibration / CancelDesenha o modelo atual; inicia o ajuste; interrompe.
Apply to Model / Apply & Re-run / DiscardGrava no modelo; grava e roda a análise; descarta.
Erro comum. Um ajuste que fecha bem contra uma única curva não é uma configuração adotada do artigo: aquelas foram fixadas por bancada e validadas por validação cruzada. Trate o seu ajuste como hipótese.
