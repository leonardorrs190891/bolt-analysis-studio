2. Fator 1 — rigidez anisotrópica do joint

A junta tem rigidez direcional: muito alta axialmente (compressão de membros sólidos), muito baixa transversalmente (limitada pela aderência por atrito). Em forma de tensor 3×3:

[K_joint(s)] = ┌ ┐ │ k_j_ax(F₀) 0 0 │ ← axial: Greenwood-Williamson │ 0 k_j_tr(stick/slip) 0 │ ← transversal: stick → alto, slip → 0 │ 0 0 k_j_θ(F₀) │ ← rotacional (Iwan-like) └ ┘

Quando carga transversal F_y excede o threshold de atrito (Pai-Hess: F_slip = 0.46·μ·F₀), a entrada k_j_tr "colapsa" e a força equivalente migra pra {F} via reação de atrito.

3. Fator 2 — acoplamento da hélice (off-diagonal de [K])

A hélice da rosca cria uma conexão geométrica entre o DOF axial x e o DOF rotacional θ:

K_xθ = K_θx = k_b · (p / 2π) ← off-diagonal (Fator 2) = k_b · lead_per_radian

Componentes da projeção da carga externa sobre a direção do filete:

c_ax(carga axial) = sin β ≈ 0.04 (componente pequena) c_tr(carga transv.) = cos β ≈ 1.0 (componente quase total) Razão = cot β ≈ 23 (M20) (vantagem ~23× transversal)

4. Vetor de estado lento s

A memória cumulativa da junta entre ciclos. Cada componente tem timescale distinto:

s = (F₀, δ_emb, δ_creep, δ_wear, θ_loose) F₀(N) — pré-carga residual [N] δ_emb(N) — embedding plástico [m] (saturating, ~50 ciclos) δ_creep(N) — creep viscoso log(t) [m] δ_wear(N) — desgaste cumulativo [m] θ_loose(N) — rotação cumulativa da porca [rad]

6. Energia elástica armazenada U(F₀)

Com k_j variando com F₀ via Greenwood-Williamson, U(F₀) não é puramente quadrática:

U_int(F₀) = F₀² / (2·k_b) ← tração no estojo (quadrática) + F₀^(2−α) · F_init^α / (2·k_j,0) ← compressão no joint (sub-quadrática) ∂U/∂F₀ = F₀/k_b + (2−α)/2 · F_init^α · F₀^(1−α) / k_j,0 = "energia liberada por queda unitária de preload" Concavidade ↑ conforme F₀ ↓ → RUNAWAY MATEMÁTICO
U_internal(F₀) — concavidade visível
∂U/∂F₀ — energia liberada por kN de preload

7. Mecanismos de perda (4 paralelos, pluggáveis)

Embedding

δ_emb(N) = δ_∞ · (1 − e^(−N/N_emb)) dδ_emb = (δ_alvo − δ_emb)·(1 − e^(−1/N_emb)) dF₀ = −k_b · dδ_emb ← perda de preload dE_emb = F₀ · dδ_emb ← dissipação plástica

Creep

δ_creep(t) = C_creep · F₀ · log(t/t₀ + 1) dδ_creep/dN = C_creep · F₀ · [log(t_n+1) − log(t_(n-1)+1)] dF₀ = −k_b · dδ_creep dE_creep = F₀ · dδ_creep ← viscoso, decaimento log

Wear (Archard)

Se F_tr > F_slip = 0.46·μ·F₀: slip_amp = (F_tr − F_slip) / k_j_tr d_wear = K_arch · F₀ · slip_amp / (H · A_contact) dF₀ = −k_b · d_wear dE_wear = 4 · μ · F₀ · slip_amp ← hysteresis loop area (= W_ext do ciclo!)

Rotational Loosening (Fator 2 ativo)

L_ax = Φ_ax_active · sin β · F_ax ← Fator 2 axial L_tr = Φ_tr_active · cos β · F_tr ← Fator 2 transversal L_total = √(L_ax² + L_tr²) T_loose = L_total · d₂/2 T_resist = μ_thread·F₀·d₂/(2cos α_t) + μ_bearing·F₀·r_eff slip_frac = max(0, (T_loose − T_resist) / T_loose) Δθ = slip_frac · (T_loose − T_resist) / k_torsional dF₀ = −k_b · (p/2π) · Δθ ← via hélice (Fator 2) dE_loose = T_resist · Δθ ← atrito no filete

8. Balanço energético

W_ext (input) + U_released = W_diss_total (hysteresis (energia liberada (Σ todas as transverso + do reservatório: dissipações: thread slip) F₀ caindo via visc + emb + ∂U/∂F₀ · ΔF₀) creep + frict + loose) Conservation residual = W_ext + U_released − W_diss_total ≈ 0 (se as taxas dos mecanismos são consistentes com ΔU)
